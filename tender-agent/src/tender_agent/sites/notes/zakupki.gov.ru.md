## Выдача
- Поиск — строка в центре главной, запуск — лупа справа или Enter.
- Сортировка — выпадающий список «Сортировать по» над выдачей: первый клик открывает список, второй выбирает пункт («Дате размещения»).
- Фильтр закона (44-ФЗ / 223-ФЗ) — флажки в «Параметры поиска»; после изменения нажми «ПРИМЕНИТЬ».

## Карточка
- Карточка открывается кликом по номеру «№ …»; документы — на вкладке «ДОКУМЕНТЫ».
