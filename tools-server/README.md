# tools-server

Инструменты для модели: файлы в `DATA_ROOT` (закупки, каталоги, выгрузки), страницы сайтов и таблицы. Вложения чата сюда не попадают, их текст уже в контексте Open WebUI.

Большой файл не читается целиком. Сначала оглавление и поиск, затем нужные страницы. Рисунок или нечитаемая ячейка запрашиваются отдельно.

## Документы

| Инструмент | Назначение |
| --- | --- |
| `list_documents` | Файлы и папки внутри `DATA_ROOT`. Тип определяется по содержимому. |
| `read_folder` | Папка закупки: мелкие файлы целиком, крупные оглавлением. |
| `read_document` | Текст одного небольшого файла. |
| `document_info` | Оглавление: число страниц и заголовок каждой. |
| `search_document` | Поиск артикула или слов. `55.32.9.024` и `55329024` совпадают. |
| `read_pdf` | Выбранные страницы PDF. Сетка таблицы вместо перемешанного текста. Продолжение через `next_cursor`. |
| `read_pages` | Прежний вызов тех же страниц. Для новых задач используйте `read_pdf`. |
| `view_page` | Одна страница или область `bbox` через Qwen-VL. Номер страницы и вопрос задаёт модель. |
| `read_docx` | Логические части DOCX, не физические страницы. |
| `list_docx_images` / `view_docx_image` | Список картинок и просмотр одной по `image_id`. |
| `render_docx` / `view_docx_page` | Физические страницы DOCX через LibreOffice. |
| `write_docx` | Новый DOCX в `exports/`. |
| `read_file` | Общее чтение с тем же продолжением. Смотрите `page_unit`: страница, слайд, кадр или список архива. |
| `read_text` | Текст, код, JSON, HTML и XML как исходник, без выполнения. |
| `read_presentation` | Слайды PPTX: текст, таблицы, заметки, ссылки на картинки. Старый PPT требует LibreOffice. |
| `view_slide` / `view_presentation_image` | Весь слайд или одна картинка слайда. |
| `read_image` | Размер и кадры PNG, JPEG, TIFF и других растров. Пиксели сам не читает. |
| `view_image` / `ocr_image` | Описание кадра через Qwen-VL или локальный OCR. |
| `list_archive` / `open_archive_member` | Состав ZIP, RAR или 7z и чтение одного файла из него. |
| `document_skill` | Короткая инструкция по формату: pdf, docx, spreadsheets, presentations, images, text, archives, legacy. |

Зрение включается само только для скана, крупной картинки, чертежа с коротким текстом и таблицы, у которой сетка не распозналась. Обычную таблицу и нужный рисунок модель заказывает через `view_page` или инструмент картинки.

## Таблицы

| Инструмент | Назначение |
| --- | --- |
| `describe_table` | Листы, заголовки и примеры. Файл целиком не читается. |
| `query_table` | Строки по фильтру, до 200 за вызов. Формулы можно вернуть отдельно от значений. |
| `fill_table` | Запись в копию XLSX. Заполненные ячейки и формулы не затираются без явного разрешения. |
| `start_table_job` / `table_job_status` | Фоновая обработка многих строк. |
| `write_excel` | Новый XLSX в `exports/`. |
| `download_file` | Скачать файл из `exports/`. |

## Прочее

| Инструмент | Назначение |
| --- | --- |
| `fetch_url` | Текст публичной HTML-страницы. |
| `GET /health` | Проверка, что сервер запущен. |
| `PUT /process` | Загрузчик для знаний Open WebUI, не инструмент модели. |

Проверка: `python -m pytest` из этой папки. Выборка по скачанным закупкам: `python eval/quality_sample.py`.
