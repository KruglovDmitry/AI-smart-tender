## Выдача
- При первом заходе поверх страницы открывается обучение (затемнение, кнопки «Дальше» и «Хорошо») — закрой его, иначе клики не проходят.
- Сортировка — список «По умолчанию» над выдачей; нужный пункт — «Дата публикации (по убыванию)». Пункты — переключатели с подписью, кликай по подписи.
- Следующие записи — кнопка «Показать ещё» внизу: список растёт на той же странице.
- (2026-10-26) Строка выдачи — лот, а не закупка: у одной закупки (SP…, Портал поставщиков) бывает 5–15 строк подряд с одним номером. 10 строк могут дать 2–3 закупки — для нужного числа жми «Показать ещё».
- В строках выдачи нет даты публикации, только окончание приёма заявок.

## Карточка
- Файлы — в блоке «Приложения к извещению», он может быть свёрнут; ссылки с пометкой «скрыт» всё равно скачиваются.
