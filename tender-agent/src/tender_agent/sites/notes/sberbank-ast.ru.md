## Выдача
- Выдача отсортирована по дате публикации, новые сверху. Если на странице уже только закрытые и старые закупки, дальше листать незачем.
- Отбор актуальных — фильтр по этапу «Подача заявок» («Этап проведения»). Если не получается выбрать его за пару действий — читай выдачу без фильтра, закрытые отсеются по срокам.

## Карточка
- Имена файлов — ссылки без адреса, скачиваются кликом по имени; у файлов раздела Банка России — только иконкой рядом.
- Рядом с файлами есть «Скачать архив доверенностей к подписям» и ссылки на подписи — это не документы закупки.

## Ловушки
- (2026-10-22) Архив документов коммерческой закупки без входа отдаётся пустым — значит нужен вход.
