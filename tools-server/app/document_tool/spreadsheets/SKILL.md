# Таблицы через tools-server

Используй для файлов, доступных инструментам на сервере. Вложения чата остаются на текущем пути Open WebUI; подключённый инструмент не означает автоматический доступ к вложению.

## Чтение

- Начни с describe_table: листы, заголовки, примеры, число формул и предупреждения.
- Получай строки через query_table с нужными колонками, фильтрами и offset/limit. Не переноси большую таблицу целиком в контекст.
- read_mode=values возвращает сохранённые значения; formulas показывает выражения; both — значения и отдельные формулы/состояние их кэша. Пустой кэш формулы не означает пустую ячейку. Формулы здесь не вычисляются, сохранённые результаты могут быть устаревшими.
- Артикулы CSV/TSV остаются строками: 00123, NA и NULL не превращаются в числа/пустоту. Excel-коды с простым форматом 00000 читаются с нулями; raw_numeric_cells показывает исходные числа. Сложные форматы Excel не имитируются.
- Для старого XLS доступны значения; для анализа формул нужна копия XLSX. XLSM можно читать, но редактирование макросов не поддерживается.

## Редактирование и создание

- fill_table изменяет существующую книгу: первая запись создаёт копию в exports. Продолжай работу по возвращённому path. Пиши по номеру строки либо key_column. Исходный шаблон вне exports сохраняется.
- По умолчанию заполняются только пустые ячейки. Для согласованного редактирования/очистки заполненных ячеек передай overwrite_existing=true; для замены формул дополнительно replace_formulas=true. Не включай эти параметры только ради обхода отказа.
- Чтобы очистить ячейку, передай null с разрешённой заменой. Для объединённых ячеек используй верхнюю левую ячейку. allowed_values ограничивает словарь; это не полная реализация Excel Data Validation.
- write_excel создаёт новый XLSX из заголовков и строк. Формулы задаются строками с =, но сервер не рассчитывает их.
- После сохранения сервер повторно открывает временный XLSX, сравнивает ячейки, формулы, стили и основные свойства книги, затем атомарно публикует результат. verification подтверждает сохранность структуры, а не правильность расчётов.
- Прочитай problems и cells_written. Частичная запись не равна успешному заполнению всей задачи. При нулевой записи книга повторно не сохраняется.
- start_table_job по умолчанию сохраняет заполненные выходные ячейки даже в частично заполненных строках. skip_filled=false разрешает переобработку обычных значений; формулы остаются защищёнными.
- XLSM не записывается, чтобы не потерять VBA. Не конвертируй Excel в PDF для редактирования: это лишит таблицу адресов, формул и структуры.
- Отдай пользователю download_url; отдельно сообщи о пропусках и о необходимости пересчёта формул в Excel/другом совместимом движке.
