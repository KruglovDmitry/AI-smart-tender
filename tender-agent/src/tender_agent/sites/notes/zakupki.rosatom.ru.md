## Выдача
- Поиск — поле на странице «Закупки», запуск Enter. Выдача сразу отсортирована по дате публикации, новые сверху.
- Строки таблицы открывают карточку кликом, ссылок у них нет.
- После возврата из карточки сайт сбрасывает поиск к общему списку: сначала прочитай всю страницу выдачи, потом открывай карточки.
- Панель «Параметры поиска» перекрывает список и пагинацию — если она открыта, закрой её, а не ищи кнопки под ней.
- Активных закупок по узкому запросу обычно немного: если на первой странице остальные закрыты, а дальше только старее — выдача кончилась.

## Карточка
- Документы — на вкладке «Документы» таблицей; скачивание — иконкой без подписи в строке файла.
