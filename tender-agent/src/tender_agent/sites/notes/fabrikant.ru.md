## Общее
- Номер процедуры выглядит как «№ 5584745-1»; «-1», «-2» — лоты одной процедуры.

## Выдача
- Строка «Введите ключевое слово, номер процедуры или ИНН», запуск — Enter: клик по лупе иногда только открывает подсказки.
- Поиск применён, если в адресе есть query=… и совпадения подсвечены жёлтым.
- С фильтром «приём заявок» выдача обычно короткая; если записей меньше, чем нужно, а следующей страницы нет — это все активные.
