# Архивы через tools-server

Для ZIP/RAR/7z сначала list_archive с offset/limit. Это список файлов, не чтение их содержимого. read_file архивов индексирует только манифест (page_unit=archive_manifest_part), search_document ищет имена членов, не скрытый текст документов.

open_archive_member(path,member) открывает один точный уникальный элемент в отдельную копию внутри DATA_ROOT и возвращает path. Имя берётся из манифеста. Затем используй инструменты формата: read_pdf/read_docx/read_presentation/read_text/read_image или табличные инструменты. Вложенный архив открывай явно тем же способом. Источник не меняется, ссылки и пути с выходом из каталога блокируются. Шифрованные элементы не читаются, пароли не запрашиваются инструментом.

Старый read_document сохраняет ограниченное чтение содержимого маленьких архивов: до 200 файлов, 128 MiB распаковки, 120000 символов и трёх уровней. Проверяй zip_files/skipped/truncated. Для больших архивов всегда выбирай элементы явно. Манифест до 10000 записей, архив до 512 MiB, выбранный файл до 64 MiB. 7z распаковывается в ограниченный буфер; RAR требует доступного unrar/bsdtar. Архивы и их содержимое не исполняются.
